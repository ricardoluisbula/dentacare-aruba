# Dutch (nl) translation: review list

The Dutch text on this website is a **machine-assisted translation that has not been professionally verified**. A fluent Dutch speaker who knows dental terminology (and, for the policies, someone who knows privacy wording) should review it before it goes live. Until then, treat the English text as the reference.

Files: `src/lib/i18n/dictionaries/nl.ts`, `nl.treatments.ts`, `nl.gallery.ts`, `src/content/nl/shared.ts`, `src/content/nl/pages.ts`, `src/content/nl/treatmentPages.ts`.

The automated test (`npx vitest run src/content -t "nl translation"`) only checks that every key exists, that no sentence is left in English, and that names, numbers and tokens are kept. It cannot judge whether the translation is accurate.

Register: formal "u" throughout. "in Aruba" is rendered "op Aruba". "Dates" is rendered "datums" (not "data"), so it is not confused with "data".
